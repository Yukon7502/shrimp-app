# 虾多多 - 云端同步版 使用说明

## 📱 功能亮点

- ✅ **多设备同步**：一台设备修改数据，所有设备自动更新
- ✅ **手机安装**：支持添加到手机桌面，像 APP 一样使用
- ✅ **离线可用**：断网时也能用，数据存在本地，联网后自动同步
- ✅ **数据安全**：数据存在自己的服务器/电脑上，不上传第三方

---

## 🚀 快速启动（3 步）

### 第 1 步：安装 Node.js

下载并安装 Node.js（版本 18 或更高）：
👉 https://nodejs.org/

安装完成后，打开终端/命令行，输入 `node -v` 能看到版本号就说明装好了。

### 第 2 步：启动服务

**Mac 电脑**：双击 `start.sh`（或右键 → 打开）
**Windows 电脑**：双击 `start.bat`

启动成功后会看到类似这样的提示：
```
🚀 启动虾多多服务...

  本机访问: http://localhost:3000
  手机访问: http://192.168.1.100:3000  （手机需连接同一WiFi）
```

### 第 3 步：手机上打开并安装到桌面

1. 确保手机和电脑连接 **同一个 WiFi**
2. 用手机浏览器（推荐 **Safari** 或 **Chrome**）打开上面显示的"手机访问"地址
3. 添加到桌面：
   - **iPhone (Safari)**：点底部分享按钮 → "添加到主屏幕"
   - **安卓 (Chrome)**：点右上角菜单 → "添加到主屏幕" / "安装应用"
4. 桌面会出现"虾多多"图标，点击即可像 APP 一样使用

## 👥 多人/多设备使用

### 方式一：同一 WiFi 下使用（最简单）

1. 一台电脑启动服务（作为服务器）
2. 所有人的手机连接同一个 WiFi
3. 每台手机都用浏览器访问服务器地址并添加到桌面
4. 数据实时同步，A 手机录入的数据，B 手机立刻能看到

### 方式二：外网访问（任何地方都能用）

需要把服务部署到云服务器上：

1. 购买一台云服务器（阿里云、腾讯云等，最便宜的就行）
2. 把整个 `shrimp-app` 文件夹上传到服务器
3. 服务器上运行 `npm install && node server.js`
4. 用服务器的公网 IP 访问（如 `http://123.45.67.89:3000`）
5. （推荐）绑定域名 + 配置 HTTPS，体验更好

**提示**：如果需要长期稳定使用，建议用 PM2 等工具让服务后台常驻运行。

## 💾 数据存储

所有数据保存在 `data/shrimp-data.json` 文件中。

- **备份**：直接复制这个文件即可
- **迁移**：把这个文件复制到新服务器的 data 目录下
- **定期备份**：建议每周复制一次这个文件到安全的地方

---

## 🔄 同步机制说明

- APP 每 **3 秒**自动检查一次服务器是否有更新
- 有新数据时自动刷新页面显示
- 顶部状态栏显示同步状态：
  - 🟢 **已同步** — 连接正常，数据是最新的
  - 🟡 **同步中** — 正在和服务器交互
  - ⚪ **离线模式** — 没连上服务器，数据只存在本机

## ⚙️ 常用操作

### 修改端口号
默认端口是 3000。如需修改，设置环境变量：
```bash
# Mac/Linux
PORT=8080 node server.js

# Windows (cmd)
set PORT=8080 && node server.js
```

### 更新版本
替换 `public/index.html` 和 `server.js` 文件即可，数据文件不会受影响。

## ❓ 常见问题

**Q: 手机打不开页面？**
A: 检查手机和电脑是否在同一个 WiFi；电脑防火墙是否允许 3000 端口。

**Q: 关闭电脑后手机还能用吗？**
A: 不能。电脑是服务器，必须开着。如果需要随时用，请部署到云服务器。

**Q: 数据会丢失吗？**
A: 数据存在 `data/shrimp-data.json` 文件里，只要这个文件不删就不会丢。建议定期备份。

**Q: 最多支持多少棚？**
A: 没有上限。点击"下一个"棚号会自动增加。

**Q: 可以多人同时录入吗？**
A: 可以。不同的人录入不同棚的数据互不影响；如果两个人同时改同一个棚同一天的数据，最后保存的会覆盖先保存的。
